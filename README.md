# Arduino UNO Remote-Controlled Car

## Description: An Arduino UNO remote controlled car involving assembly, electronics, troubleshooting and programming

## Overview:
I built and programmed a remote-controlled robot car using an Arduino UNO microcontroller, integrating and infrared (IR) receiver with an Osoyoo kit. I gained experience combining mechanical assembly, electronics and programming to create a functioning car.

## Tasks I completed:

- Assembled the robot chassis along with the mechanical components
- Integrated the electronic components such as the motor driver, and Arduino UNO with the mehcanical components like the wheels and motors.
- Programmed the movements of the robot and the functions of the remote control
- Troubleshot any issues that arose with the hardware or code
- Made minor adjustments to ensure the optimisation of the car

## Mechanical Assembly
This project gave me a strong foundation in the ways in which mechanical components sit alongside electrical components. It taught me how to integrate each of the parts into the build without compromising the appearance or the function.

## Electronics & Programming
As a mechanical engineering student, I wanted to gain a better understanding of electrical components and how they work alongside mechanical components. I worked with:

- Arduino UNO
- DC motors
- Motor driver
- Battery/ Power supply
- C++ (arduino)

## What I learned:
This project gave me practical experience in troubleshooting and testing each part of the system without restarting the project each time. I did this by checking the power supply, wiring, connections, motors and the code. I gained a lot of experience in isolating individual components to identify where the problem occurred.\
\
This project also increased my interest in developing my ability to work with mechanical aspects of engineering alongside the electronics and electrical systems. Working with the motors, wiring and the physical components of the car allowed me to understand how each of these aspects interacts within a project. \
\
I also developed a greater understanding of how software is integrated into projects. I initially studied an existing piece of code to understand how the IR receiver, movement commands and motor control worked together. I then redesigned some of the control logic into a simpler format and tested each of the changes individually. This gave me a lot of experience with debugging and modifying existing code as within mechanical engineering I do not normally see this side of projects.

## Areas for improvement:
I am hoping to revisit this project soon to make the car more autonomous in two stages:
1. **Avoiding obstacles** I am planning to add an HC-SR04 ultrasonic sensor to detect obstacles
2. **Following a line** After this, I will add a TCRT5000 infrared reflectance sensor. This would allow my car to follow a black line on the floor while avoiding obstacles
